# STEM Scholars Foundation website (V1)

Plain HTML/CSS/JS. No build step. Push the folder contents to your host with git.

## Fill in before launch (search for `TODO` and `YOURDOMAIN`)
- Mission statement, Our Story, founder bios: about.html
- Volunteer application link: replace `#TODO-volunteer-application-link` in every file
- Contact email: replace `info@YOURDOMAIN.org` in every file
- Contact form: replace `YOUR_FORM_ID` in contact.html (Formspree or similar; static sites can't send email themselves)
- Logo: already wired in (assets/logo.png, logo-icon.png, favicon files)
- Social links: uncomment in the footer of each page
- Impact numbers: hidden on purpose until real (see comment in index.html)
- Blog: blog.html exists but is not in the nav. Add it when ready
